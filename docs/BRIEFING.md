## 2. СДЕЛАНО (desktop_pet\)

- `sounds.py` — CC0-сэмплы из `assets/sounds/<питомец>` (варианты, set_pet) + numpy-синтез как фолбэк (временные wav в %TEMP%, чистятся atexit).
- Трей: пауза/спрятать/показать/раз&меньше/раз&больше/звук/выход. `settings.json` сохраняется при выходе.

## 4. ⚠️ ОШИБКИ, С КОТОРЫМИ СТОЛКНУЛСЯ (НЕ ПОВТОРЯТЬ)
1. **Long Path**: Store-Python живёт в `C:\Program Files\WindowsApps\...qbz5n2kfra8p0\...` — путь site-packages > 260 символов, `pip install PySide6` (полный пакет с Addons/WebEngine) **падает** при распаковке `qml/Qt/labs/.../objects-Debug/...obj`. **Решение:** `-t 'C:\pylib'` (короткий путь). Если вдруг ставишь в site-packages — только Essentials.
2. **PowerShell 5.1**: `python -c "..."` с вложенными кавычками — катастрофа; пути в одинарных кавычках (`'C:\...'`); stderr от нативных exe (Qt-предупждения вроде «This plugin does not support raise()») делает `ExitCode=1` при рабочем результате — смотри вывод, а не код.
3. **Фон артов не чистый белый**: (251–252, серый). Первый фильтр «hi>=244 и spread<=26» съел **кремовый животик** (тоже светлый!). Правильно: flood fill от краёв листа (scipy.ndimage.label + компоненты, touching border). Кремовый замкнут тёмным контуром.
4. **Осколки Kimi**: на листах (особенно `sleep.png`/реакции) мелкие шумовые пятна — `keep_largest` после нарезки ЯЧЕЙКИ, не всего листа (иначе остаётся один спрайт).
5. **PySide6 6.12 API**: `QAction` в QtGui (не QtWidgets); `Qt.Transform` → `QTransform` (QtGui); `QImage` не имеет `scaledToHeight`/`scaled` — только `QPixmap`; `QPixmap.toIcon()` нет — `QIcon(path)`; `QSoundEffect` только в Addons; `np.asarray(img.getchannel('A'))` read-only — `.copy()`.
6. **API-отвалы Cline**: `ECONNREFUSED 10.0.0.128:8080` — прокси пользователя; при этом просто ответь «API не отвечает, перезапусти запрос», не выполняй ничего.
7. **Вложения чата** — base64 в `*.messages.json` сессий (`content[].type=="image" → "data"`), файлов нет. Скрипт-пример: `C:\Users\iriks\.cline\data\workspaces\chat\_extract_images.py`.
8. **Копирование картинок**: `Copy-Item -LiteralPath` (есть пробелы в именах, напр. `sit idle.png` в Downloads).
9. **Скриншоты через GetDIBits (32bpp)**: байты хранятся в порядке **BGRA**, не RGBA! Без инверсии каналов `arr[:, :, ::-1]` хомяк (оранжевый R≈200/B≈87) выглядит на «скриншоте» как **голубое существо**. Это баг диагностического скрипта, а не приложения. Все скрипты-капчеры в `desktop_pet\` (`_find_win.py`, `_ab_crop.py`, `_scan_blue.py`, `_diff_ab.py`) уже исправлены.
10. **PyInstaller onefile = 2 процесса** (бутлоадер + ребёнок-приложение): это НОРМА, не баг.
11. **Кэш `_MEI*` в %TEMP%**: каждый запуск onefile-EXE оставляет папку `_MEIxxxxx` (~60–100 МБ) — при частом тестировании их копятся десятки (1.9 ГБ!), диск C: может **заполниться до нуля**, тогда инструменты не пишут (ENOSPC). Чистить: `Get-ChildItem $env:TEMP -Directory -Filter '_MEI*' | Remove-Item -Recurse -Force` (только когда EXE не запущен).
